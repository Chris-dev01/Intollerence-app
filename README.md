# Intol – Application de détection des intolérances alimentaires

**Intol** est une application mobile développée avec **Flutter** qui aide les utilisateurs à identifier rapidement si un produit alimentaire est compatible avec leurs **intolérances ou allergies**.  
Grâce au **scan de code-barres**, l’application analyse les ingrédients et fournit un retour clair pour aider à faire des choix alimentaires plus sûrs.

> **Projet en cours de réalisation**  
> Cette application est actuellement en développement. Certaines fonctionnalités sont incomplètes ou susceptibles d’évoluer.

---

## Fonctionnalités

-  **Authentification utilisateur**
  - Inscription / Connexion via **Firebase Authentication**
  - Gestion sécurisée des sessions
-  **Scan de codes-barres**
  - Lecture des produits alimentaires
  - Analyse des ingrédients *(en cours)*
-  **Profil utilisateur**
  - Récupération des informations depuis Firebase
  - Déconnexion sécurisée
-  **Gestion des intolérances alimentaires** *(à venir)*
-  **Historique des scans** *(à venir)*
-  **Interface moderne et fluide**
  - Design responsive
  - Animations et transitions douces
